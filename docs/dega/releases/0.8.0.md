# Canon 0.8.0 — Cardano registration and cross-chain discovery

Register a Canon chat identity with a locally generated Cardano wallet and native DEGA.
Discover contacts across Ethereum and Cardano using the same chat transport. Public
Koios endpoints provide chain access without a provider API key.

The new registry stores one authenticated record per identity and uses an MPF index
for permanent username, wallet and chat-key reservations. It supports owner renewal
and invitations without the earlier eight-registration limit. Transaction journals
protect retries and confirmation recovery.

The included deployment is an opt-in **mainnet test registry**, with a **15.1234 DEGA**
registration payment plus ADA requirements. The final production registry, pricing and
wallets are still pending. This release does not bridge or burn collected tokens.

Setup: [Cardano guide](../../../cardano/README.md). Install Node.js 26+, install the
Cardano companion, and select the included MPF deployment manifest. Existing Ethereum
configuration remains available.

Validation includes 95 Aiken checks, 65 client tests, Python integration checks, packaging
verification and a user-confirmed mainnet registration. Benchmark results are local
measurements, not a production audit or a guaranteed fee quote.
