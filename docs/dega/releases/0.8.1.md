# Canon 0.8.1 — production Cardano registry

Mainnet now selects the production Cardano registry by default. Its initial registration
amount matches Ethereum: **6,719,270 DEGA**, valid for **365 days**. ADA requirements are
additional. The on-chain quote remains authoritative if the admin changes pricing later.

The production deployment uses separately confirmed deployer and collector wallets. Its
public manifest is bundled with the Python distribution, so a fresh install does not need
a local deployment file. Explicit demo overrides and existing wallets are preserved.

Install the updated Cardano companion, select Cardano in Chat, fund the displayed wallet
and review the quote before registering. Remove an explicit demo deployment override if
you want to switch that installation to production. See the [Cardano guide](../../../cardano/README.md).

The new recording demo remains a separate deployment at 15.1234 DEGA and is not the default
for public installations. The production validator uses the same tested MPF implementation;
this release changes deployment parameters and default configuration, not contract logic.
